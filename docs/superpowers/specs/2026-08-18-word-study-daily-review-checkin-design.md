# 单词今日回顾与打卡设计

## 目标

为单词背诵模块增加今日学习回顾、UTC 打卡日历和连续打卡统计，并将个人主页中的学习设置整理为集中折叠区。

## 已确认范围

- 今日回顾合并当天首次学习和旧词复习记录，并标记活动类型。
- 新词学习或复习完成后，完成页都直接展示今日回顾；单词首页也保留今日回顾入口。
- 只有完成当天的新词学习组才完成打卡；单独完成旧词复习不打卡。
- 打卡日历展示当前月份，支持前后月份切换。
- 每个用户每天最多一条打卡记录；首次完成当天新词学习时记录 UTC 时间，后续重复完成不覆盖。
- 今日回顾后端分页，默认每页 20 条。
- 学习设置继续保留在个人主页，但集中为一个独立折叠区。
- 所有日期边界和连续天数使用 UTC。
- 数据库允许破坏式迁移；不修改历史迁移。
- 设计文档不提交到 Git。

## 方案选择

采用“学习活动流水表 + 用户打卡日表”方案。

直接从会话项完成时间查询虽然改动少，但会让回顾强依赖会话内部结构，无法稳定处理同一单词当天多次活动，也不利于后续扩展其他学习活动。将进度日期集合存入 JSON 则会增加 PostgreSQL 查询、分页和并发更新复杂度。独立活动流水能明确表达用户完成了哪种学习活动，并以数据库约束保证幂等。

## 数据模型

### `word_study_activities`

字段：

- `Id`
- `UserId`
- `WordId`
- `SessionId`
- `SessionItemId`
- `ActivityType`：`Learning` 或 `Review`
- `CompletedAtUtc`
- `CreatedAt`

约束和索引：

- `(SessionItemId, ActivityType)` 唯一，避免重复提交重复写入活动。
- `(UserId, CompletedAtUtc, WordId)` 用于 UTC 日期回顾查询和稳定分页。
- 用户、会话和会话项按现有关系处理生命周期。
- 单词墓碑删除后活动记录保留，但用户回顾查询过滤不可见单词。

### `word_study_check_ins`

字段：

- `Id`
- `UserId`
- `StudyDateUtc`：UTC 自然日
- `CheckedInAtUtc`：首次打卡时间
- `CreatedAt`

约束和索引：

- `(UserId, StudyDateUtc)` 唯一。
- `(UserId, StudyDateUtc)` 索引支持日历月份查询和连续日期计算。
- 打卡插入使用唯一约束兜底，重复完成同一天任务保持幂等。

## 后端 API

### 今日回顾

`GET /word-study/review/today?page=1&pageSize=20`

响应包含：

- `studyDateUtc`
- `items`
- `page`
- `pageSize`
- `totalCount`
- `totalPages`

每个回顾项包含：

- `wordId`
- `headword`
- `activityType`
- `completedAtUtc`
- 有序释义
- 例句和翻译
- 单词音频资源 ID
- 例句音频资源 ID
- 当前收藏状态

查询只读取当前 UTC 日期，按 `completedAtUtc` 降序、`WordId` 稳定排序。同一个单词当天同时有新学和复习活动时保留两条，并分别标记活动类型。

### 打卡日历

`GET /word-study/check-ins?year=2026&month=8`

响应包含：

- `year`
- `month`
- `checkedInDates`：日期和首次打卡时间
- `currentStreak`
- `longestStreak`
- `totalCheckInDays`

日历只返回指定月份的日期；连续天数和累计天数基于该用户的全部历史打卡记录计算。若今天未打卡，`currentStreak` 从昨天开始计算，今天不立即视为断档。

### 完成命令事务

新词完成命令：

1. 完成会话项和用户学习进度。
2. 写入一条 `Learning` 活动。
3. 当最后一个有效项目完成时，插入当天打卡记录。
4. 提交同一事务。

复习完成命令：

1. 完成会话项和复习进度。
2. 写入一条 `Review` 活动。
3. 提交事务，不创建打卡记录。

重复提交、并发竞争和唯一约束冲突都必须幂等；活动或打卡写入失败时，学习状态一并回滚。

## 用户端布局

### `/words`

页面按以下顺序展示：

1. 新词学习和旧词复习任务区。
2. 当前月份打卡日历、连续天数和累计天数。
3. 今日回顾分页列表。

今日回顾列表项展示词头、活动类型、释义、例句、单词音频、例句音频和收藏按钮。列表有独立加载、空状态、错误和重试状态；收藏失败只回滚当前项。

### 完成页

新词学习和旧词复习完成摘要下面直接展示今日回顾。回顾加载失败不影响已完成状态，支持独立重试。原有“返回单词首页”和“再学一组/再复习一组”操作保留。

### 个人主页

学习设置仍位于个人主页，但与学习统计、收藏本和停止复习列表分组整理为“单词学习”区域中的独立折叠区，默认收起。设置仍提供新词数量、复习数量、独立校验、保存错误提示和草稿保留。

音频播放继续复用浏览器原生适配的现有 `AudioPlaybackButton`，不新增专属播放器组件。

## 异常与安全

- 今日回顾和日历错误彼此隔离，分别提供重试。
- 回顾只读取当前认证用户的活动和可见单词。
- 打卡唯一键冲突按已完成处理。
- 活动唯一键冲突按已存在处理。
- 日期、月份和分页参数使用现有 FluentValidation 规则。
- 后端统一使用 UTC；前端只负责日期格式化。

## 测试策略

后端覆盖：

- 新词完成写入活动和打卡；复习完成只写活动。
- 重复提交、并发提交和唯一约束竞争不重复写入。
- 今日回顾分页、活动类型、UTC 日期边界和不可见词过滤。
- 日历月份查询、当前连续天数、最长连续天数和累计天数。
- 用户数据隔离和 OpenAPI DTO 契约。

前端覆盖：

- 今日回顾加载、空状态、分页、失败重试。
- 词头、释义、例句、音频和收藏交互。
- 完成页和首页入口。
- 日历月份切换、日期状态和连续天数。
- 学习设置折叠、保存失败和草稿保留。
- 窄屏布局和按钮可访问名称。
